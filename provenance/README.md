# Proof of training

Everything Gate 2 section 3.1 asks for, and the honest state of each item.

AGBE is a weight-level fine-tune, not prompt engineering, so all of the
proof-of-training artifacts apply.

## Round 1 adapter

**The adapter for the shipped v13 weights no longer exists.** It was written to
`/kaggle/working/out/adapter` in a Kaggle session that has since expired, and
nothing outside the GGUF was downloaded before the session ended. The notebook
committed to this repo is the generated source, so its cells carry no outputs
either, and `report_to=[]` with `logging_steps=5` meant the loss values were only
ever printed to a cell that is now gone.

That is a real gap in the Round 1 artifact and it is stated rather than papered
over. It is also the reason `train_lora.py` now writes `provenance/` beside the
adapter *before* the merge step, so a bundle exists on disk from the moment
training finishes.

## Dataset

Name: the AGBE agriculture corpus. Original work, built for this challenge.

- Source: composed by [`../corpus/generate.py`](../corpus/generate.py) from
  [`../corpus/facts.json`](../corpus/facts.json), a hand-curated fact base of
  established agricultural extension practice, plus hand-written exemplars in
  `../corpus/gold_*.py`.
- Size: see `run_manifest.json` → `train_examples`; the file itself is committed.
- Licence: same as this repository, and it contains no third-party text. Nothing
  was scraped and nothing was generated by another model. `generate.py` cannot
  emit a claim that is not in `facts.json`, which is the point of composing the
  corpus rather than collecting it.
- The base model is Gemma 3 1B, used under the
  [Gemma Terms of Use](https://ai.google.dev/gemma/terms).

## Reproducing

```bash
python corpus/generate.py                     # rebuild the corpus from the fact base
bash provenance/merge_and_quantise.sh         # train, merge, convert, quantise
LLAMA_CLI=<path> provenance/compare_to_base.sh <base.gguf> <agbe.gguf>
```
